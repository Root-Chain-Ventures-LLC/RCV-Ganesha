# Ganesha

Vehicle and driver compliance tracker for HR and stakeholders: who drives which work truck, and whether the things that must stay current (insurance cards, registration, driver's licenses, inspections, gas cards, ferry cards, parking passes) actually are. Integrates with Microsoft 365 for the staff directory and sign-in, and with Geotab for vehicles, current driver and odometer.

This is the **public release repository**. It will carry the install artifacts (Docker
Compose file, install script, Kubernetes manifests) and release notes for each published
version. The container image is published to GitHub Container Registry alongside each
release. No release has been published yet; install instructions arrive with the first one.

Source code is not published. See [CONTRIBUTING.md](CONTRIBUTING.md) for how to report
bugs and request features.
